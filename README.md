# El Pollo Loco 🐔🌵

A vibrant, action-packed "Jump-and-Run" game built with Vanilla JavaScript and Object-Oriented Programming. Join Pepe as he fights his way through the Mexican desert to defeat the legendary Endboss!

---

## 🚀 Key Features

- **Dynamic Animations**: Smooth, frame-by-frame animations for character movement, jumping, and idle states.
- **Enemies**: Battle different types of chickens and a challenging Endboss with a dedicated health bar.
- **Physics Engine**: Custom implementation of gravity, collisions, and throwable objects (salsa bottles).
- **Collectibles**: Gather coins and salsa bottles.
- **Responsive Design**: Optimized for both desktop (keyboard) and mobile (touch controls) gameplay.
- **Soundscapes**: Immersive background music and sound effects for a complete gaming experience.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+).
- **Graphics**: HTML5 Canvas for high-performance 2D rendering.
- **Architecture**: Clean, scalable Object-Oriented Programming (OOP) structure.
- **Controls**: Event-based input system for Keyboard and Touch.

## 🏁 Getting Started

### Prerequisites
A modern web browser (Chrome, Firefox, Safari, or Edge).

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/lucasxgraf/el_pollo_loco.git
   ```
2. Open the project folder.
3. Simply open `index.html` in your browser or use a "Live Server" extension for the best experience.
